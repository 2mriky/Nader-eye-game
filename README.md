# عين نادر · Nader's Eye — v3

## تشغيل
    python3 -m http.server 8000
افتح http://localhost:8000  ← **لازم سيرفر**، الدبل كليك مش هيشتغل.

## المشاهد — data/*.json
| type | معناه |
|---|---|
| `find` | تدوس تتشال وتتشطب من الشريط. **متدخلش الشنطة** |
| `tool` | تتشال وتدخل **الشنطة** |
| `container` | محتاجة أداة (`requires`) — تدوس عليها أو تسحب الأداة فوقها |
| `talk` | كلام بس |

`yields` اسم الحاجة في الشنطة · `requires` المطلوب للفتح
`rect` منطقة النقر · `objectives` اللي بيظهر في الشريط (٤ في المرة)

## المقاسات
كلها في بلوك `L` أول `game.js`.
